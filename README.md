# HorizonTechX Calculator Pro

A premium, responsive calculator web application built with vanilla
HTML5, CSS3, and JavaScript for the **HorizonTechX Frontend Development
Internship**. It features safe expression parsing (no `eval()`),
calculation history, memory functions, dark/light themes, clipboard
copy, and PNG screenshot export.

## Features

- All four arithmetic operations with correct operator precedence
- Decimal numbers with floating-point precision handling
- Percentage, sign toggle, square root, and square functions
- Safe custom expression parser — **no `eval()`**
- Division-by-zero and invalid-expression error handling
- Keyboard support with visible shortcut hints
- Dark / light theme with localStorage persistence and system preference detection
- Calculation history with timestamps, reuse, per-entry copy, and clear-with-confirmation
- Memory functions: MC, MR, M+, M−
- Copy current result to clipboard (with graceful failure handling)
- PNG screenshot export via `html2canvas`
- Fully responsive (320px → large desktop)
- Accessible: semantic HTML, ARIA labels, visible focus, reduced-motion support

## Technology Stack

- HTML5
- CSS3 (external stylesheet, CSS custom properties for theming)
- Vanilla JavaScript (ES2020, no frameworks)
- [Remix Icon](https://remixicon.com/) via CDN
- [html2canvas](https://html2canvas.hertzen.com/) via CDN
- Google Fonts: Inter + JetBrains Mono

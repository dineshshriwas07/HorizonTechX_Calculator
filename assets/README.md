# Assets

This folder is reserved for static assets such as screenshots used in the
main README, a favicon, or branding images.

Suggested contents (not required for the app to run):

- `screenshot-light.png` — Light-mode calculator preview
- `screenshot-dark.png`  — Dark-mode calculator preview
- `favicon.png`          — Optional site favicon

Add screenshots to this folder and reference them from the root `README.md`.
